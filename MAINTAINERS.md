## Responsibilities

- Review and merge pull requests.
- Triage issues and apply labels.
- Cut releases and write the release notes.
- Respond to security reports per [SECURITY.md](SECURITY.md).

## Contact

For project matters, open an issue or a discussion. For security reports, use the
private process in [SECURITY.md](SECURITY.md). For Code of Conduct concerns, see
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
